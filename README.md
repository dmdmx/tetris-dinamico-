
# 🎮 Tetris Dinámico

**Tetris Dinámico** es un videojuego clásico desarrollado en Python utilizando la biblioteca Pygame. Disfruta de una experiencia dinámica con controles intuitivos, rotación de piezas, caída instantánea, sistema de reserva y efectos de sonido.

## ✨ Características

- Movimiento de piezas en tiempo real.
- Rotación de bloques.
- Caída instantánea.
- Sistema para guardar e intercambiar piezas.
- Control de sonido.
- Pausa durante la partida.
- Interfaz gráfica desarrollada con Pygame.

## 📥 Instalación y ejecución

### Requisitos

- Python 3.10 o superior.
- Pygame.
- Git (opcional).

### 1. Descargar el proyecto

Descarga el repositorio desde GitHub utilizando **Code → Download ZIP**.

También puedes clonarlo desde una terminal:

```bash
git clone https://github.com/dmdmx/tetris-dinamico-
```

Entra en la carpeta del proyecto:

```bash
cd nombre-del-repositorio
```

### 2. Instalar las dependencias

Ejecuta:

```bash
python -m pip install -r requirements.txt
```

### 3. Iniciar el juego

Ejecuta:

```bash
python main.py
```

¡Listo! Ya puedes comenzar a jugar.

## 🕹️ Controles

| Tecla | Acción |
|---|---|
| ⬅️ Flecha izquierda | Mover pieza a la izquierda |
| ➡️ Flecha derecha | Mover pieza a la derecha |
| ⬇️ Flecha abajo | Acelerar caída |
| ⬆️ Flecha arriba / X | Girar pieza |
| Espacio | Caída instantánea |
| C / Shift | Guardar pieza |
| P / Esc | Pausar o reanudar |
| M | Activar o silenciar sonido |
