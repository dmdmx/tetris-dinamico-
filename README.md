# Tetris Dinámico

Juego de Tetris hecho con Python y Pygame.

## Ejecutar

```bash
python -m pip install -r requirements.txt
python main.py
```

## Controles

- Flechas izquierda/derecha: mover
- Flecha abajo: bajar
- Flecha arriba o `X`: girar
- `Espacio`: caída instantánea
- `C` o `Shift`: guardar pieza
- `P` o `Esc`: pausar
- `M`: silenciar o activar sonido
